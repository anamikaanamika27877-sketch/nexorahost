FAQ

Questions, answered.

Learn how the NexoraHost prototype is intended to work.

Will Minecraft servers run 24/7?

Not yet. A connected, always-on server machine and server-management backend are required. A website alone cannot run Minecraft servers continuously.

Can users create their own servers?

The website shows the intended flow. Automatic server creation will only work after a secure backend and server-management API are connected.

Can I use mods and plugins?

The planned platform supports Paper and Purpur for plugins, and Fabric or Forge for compatible mods. Actual installation requires a working server and compatible files.

Can users pay using UPI?

UPI payments are not connected in this prototype. A suitable payment provider, server-side verification and order management must be configured first.

Is login working with real accounts?

No. The login and registration forms are frontend demos. Never use a browser-only demo to protect real accounts, payments or server controls.
